# Local Windows Deployment Guide

## Prerequisites
- Node.js (`v18+` or `v24`)
- Local MongoDB Server (`MongoDB Server` service running on `127.0.0.1:27017`)

## Installation Steps
1. Run `scripts/install.bat` once to install dependencies and build production assets.
2. Run `scripts/start.bat` to launch the application.
3. Access in browser at `http://localhost:5000`.
