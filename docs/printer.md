# Barcode Scanner & Thermal Printer Setup

## USB Barcode Scanner
- Connect any standard USB barcode scanner.
- Operating mode: Keyboard emulation (HID mode).
- Standard barcodes: EAN-13, Code-128, or custom numeric barcodes (e.g., `100001`).

## Thermal Receipt Printer Setup
- Supports 58mm and 80mm POS Thermal Receipt Printers.
- Configurable under **Shop Settings** -> **Receipt Thermal Paper Width**.
- Automatic browser print trigger pops up immediately post bill checkout.
